This UI's test API

GET/api/host

Worker host, this UI's port, and the learning gate.

curl -s http://127.0.0.1:PORT/api/host
POST/api/decide

Body: {mode, text, risk, train, labels:[{name,desc}]}. Returns the decide() result (answer, via, tier, p{}, best, p_best, coverage, xlm, recorded, held, disputed, t_lookup, t_xlm, ms).

curl -s http://127.0.0.1:PORT/api/decide -H 'Content-Type: application/json' \
  -d '{"mode":"choice","risk":"medium","train":false,"text":"the house is on fire",
       "labels":[{"name":"urgent","desc":"act now: an outage or emergency"},
                 {"name":"later","desc":"can wait: a newsletter"},
                 {"name":"careful","desc":"read closely: a contract"}]}'

The XLM worker API (bare-metal server, port 4780)

    
GET/api/status

      
curl -s http://$S1_WORKER_HOST:4780/api/status | python3 -m json.tool

    
POST/api/auth → POST/api/embed

      
TOKEN=$(curl -s -X POST http://$S1_WORKER_HOST:4780/api/auth \
          -d '{"username":"<user>","password":"<pass>"}' \
        | python3 -c 'import sys,json;print(json.load(sys.stdin)["token"])')
curl -s -X POST http://$S1_WORKER_HOST:4780/api/embed -H "X-Caramel-Token: $TOKEN" \
     -d '{"ids":[0,35378,8999,2]}' | python3 -m json.tool
# -> { "vector":[1024 ints], "scale":n, "tokens":k, "model_sha256":"…", "sha256":"…" }

      
Credentials live in ~/.config/maned/xlm.env (mode 600); never put them in a repo or a URL.
